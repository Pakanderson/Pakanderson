## 👨‍💻 Featured Projects

### 🎓 EduMatch: Predicting and Preventing Student Dropout
**Domain:** Machine Learning & Education Analytics
> An end-to-end project that predicts which students are at risk of dropping out so advisers can intervene early.

* **Classification:** Random Forest compared against Logistic Regression and Decision Tree baselines on a stratified 80/20 split, handling a 62/38 class imbalance. **80% recall, 85% precision.**
* **Beyond prediction:** Cohort clustering plus a local RAG layer (Ollama) to support advising, delivered as an interactive app ([the-edumatch-app](https://github.com/Pakanderson/the-edumatch-app)).
* [View Project Repository ➡️](https://github.com/Pakanderson/edumatch-student-retention)
